# ============================================================
# 47. COVERAGE RULES
# ============================================================

Model Coverage deve possuir critérios claros e documentados.

Não permitir que o modelo atribua livremente um nível sem critérios.

Exemplo:

FINANCE = UNKNOWN

quando praticamente não existem informações financeiras.

FINANCE = LIMITED

quando conhece faturamento, mas desconhece custos e margem.

FINANCE = PARTIAL

quando conhece faturamento, alguns custos e margem aproximada, mas existem lacunas relevantes.

FINANCE = SUFFICIENT

quando existem dados suficientes para determinada classe de análise.

FINANCE = STRONG

quando existem dados atuais, consistentes, contextualizados e historicamente úteis.

IMPORTANTE:

Coverage é contextual.

SUFFICIENT não significa:

"Sabemos tudo sobre as finanças."

Significa:

"Existe informação suficiente para determinadas análises."
