# SeedAI — FREE first value release

Isolated release based on the published application. Two short local context questions prepare a single analysis request. A grounded, validated and persisted next step precedes the PRO invitation. Existing lifetime usage limits, financial reservations and tenant checks remain in place.

This release does not activate subscriptions or introduce database migrations. The existing public prelaunch access restrictions remain separate deployment controls.

## Verification

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run security:scan`
- `npm run build:verify`

Browser fixtures: `node scripts/test-free-browser.mjs`, with the Playwright test browser installed in `.test-build/playwright-browsers`. Fixture browser tests do not call a paid provider. Private operational evidence and environment credentials are excluded from this branch.
